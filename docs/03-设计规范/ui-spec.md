# UI 设计规范

> 打包启动修正（2026-09-14）：首启标题为“欢迎使用 OpenCode 用量监测”；重新探测/手动选择/开始使用位于同一行，跳过按钮放底部单独一行；说明和路径在卡片宽度内换行。
> 主窗先计算自适应高度再绘制卡片，指标/进度条/状态不重叠；状态左对齐，在卡片内换行，错误提示另起一段；指标顺序按显示内容配置。

> 2026-09-14 数据层修订：输入默认总输入；官网 token 优先、本地补缺。数据已读取但缓存无法保存时，仍显示本次数据并给出中文提示。本次不改布局或交互，不追加 UI 验收结论。

> 风格：**Apple/macOS 面板风**（用户 2026-08-12 改版要求：更透明 + 苹果风格）
> 真 Acrylic 实测不可靠弃用，用 `-alpha`（默认 0.78，设置窗可调 0.50~0.95）半透明 + `-transparentcolor` 抠角圆角
> 深浅色双主题：默认跟随系统（注册表 AppsUseLightTheme），设置窗可选浅色/深色（配色见 `src/theme.py`）

## 字体

- 数字：**Segoe UI 10 常规**（与标签同风格、不加粗，用户要求；旧 14 bold 弃用）
- 标签/按钮：Segoe UI 9；状态栏：Segoe UI 8
- 开启 DPI 感知（`SetProcessDpiAwareness`），防模糊

## 布局（250×182，均衡两端对齐）

```
┌──────────────────────────┐
│ ◀ 8月12日(周三)  日 周 月 ▶ │  ← y28：导航 ◀▶ + 范围 + 粒度标签（当前粒度粗体深色）
│ ──────────────────────── │  ← y44：极浅分隔线
│  输入          17.7M      │  ← y66，行距 28（标签左灰 / 数字右深常规，两端对齐）
│  输出           2.2M      │
│  命中率          98.3%    │
│  费用          $5.50      │  ← 可选字段（官网口径，默认显示；未同步显示 —）
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░  │  ← y136~143：浅灰轨道 + 彩色圆角填充
│ ⟳ 已同步 16:51 · 1分钟自动 │  ← y164（anchor=s），文字底距卡片底 14px
└──────────────────────────┘
```

> 指标口径（2026-08-13 用户确认，官网计价口径）：**输入 = 总输入**（新鲜输入 + 缓存读 + 缓存写，官网 usage 表 input 列）；命中率 = 缓存读 ÷ 总输入。
> **默认显示四项**：输入总 / 输出 / 命中率 / 费用；**自定义可选**：新鲜输入 / 缓存读 / 缓存写 / 推理 / 总 token / 请求次数（设置窗"显示内容"勾选）。
> **窗口自适应**：宽固定（250），高随要素行数自动变化（行高 28px）。
> **费用**（2026-08-12 新增）：以官网 opencode.ai 账单为准；数据源 = 官网 server function + 用户浏览器 cookie（设置窗"官网同步"分区配置）；日/周/月 = 对应日期范围官网费用求和；未同步/失败显示 `—`。

## 交互

| 操作 | 行为 |
|---|---|
| 左键按住窗口任意处 | 拖动窗口（设置窗勾选"锁定窗口位置"后不可拖动） |
| 点 ◀ ▶ | 按当前粒度翻历史（日→翻天，周→翻周，月→翻月） |
| 点范围文字 | 弹月历，选任意日期 → 切到"日"粒度并跳转 |
| 点 日/周/月 | 切换粒度，回到最新（今天的日/本周/本月） |
| 右键 | 菜单：刷新 / 置顶（勾选切换，取消置顶时任务栏出现入口可找回）/ 设置 / 关于 / 退出 |
| 命中率进度条 | 只读展示（轨道+填充） |

## 设置窗（400×560，分五节）

| 分节 | 内容 |
|---|---|
| 连接 | db 路径输入 + 浏览… / 重新探测 / **测试读取**（验证可读并报告会话数）+ ⓘ 说明弹窗（opencode.db 是什么 / 默认位置） |
| 外观 | 主题三选 radio：跟随系统 / 浅色 / 深色（切换即时换肤）；**透明度滑条**（Apple 风格自定义滑块，0.50~0.95，拖动实时预览主窗） |
| 行为 | 刷新间隔下拉 1 / 2 / 5 / 10 / 30 分钟；数字格式 radio：缩写 1.2K / 完整 1,234,567；启动时置顶；锁定窗口位置（锁定时不可拖动）；开机自动启动 |
| 官网同步 | workspace ID 输入（wrk_…）；**cookie 输入**（密码样式）+ ⓘ 获取指引；**测试读取**（拉当月，显示最近 3 天费用与总和）；启用开关 |
| 关于 | 版本 0.3 · 数据目录 + 打开数据目录按钮 |

> 无极缩放：拖右下角/右/下边缘任意缩放（180x120~600x400），尺寸自动记忆（2026-08-12 晚已实现）。
> 官网同步（2026-08-12 新增）：费用以官网为准；cookie 从浏览器 F12 → Network → 请求头 Cookie 复制；主窗右键菜单"同步官网费用"手动刷新；失败不影响本地 token 显示。

## 月历弹窗

- Toplevel 小窗：标题 ◀ 2026年8月 ▶（可翻月），7 列星期表头（一~日，周一起），42 格
- 今天苹果蓝高亮；点击某日 → 关闭弹窗，主窗显示该日（粒度切到"日"）

## 文案（中文）

- 粒度标签：`日` `周` `月`
- 日期格式：日 `8月12日(周三)`；周 `8月10日~8月16日`；月 `2026年8月`
- 状态栏：`⟳ 已同步 HH:MM · 1分钟自动` / `正在加载…` / 错误信息（红色）
- 错误提示：`未找到数据源，请在设置中指定 opencode.db 路径`
- 多开提示：`程序已在运行`（原生弹窗）
